Cutline

Load a track and it charts itself from the drums — kicks low, snares in the middle, cymbals up top. Everything else is adjustable from inside the headset.

Pick an audio file to begin.

Drop an MP3 named song.mp3 next to this file and it loads automatically. Or add ?song=mytrack.mp3 to the URL.
In the headset: B or Y opens the menu — calibration, hit window, density, speed and exit all live there.
