Cutline

Load a track and it charts itself from the drums. Difficulty changes which instruments get charted, not just how many blocks come at you.

Easy — kick and snare only, locked to the quarter note.
Normal — the full kit, exactly where it lands.
Hard — kit plus the strongest melodic attacks.
Expert — everything, with more doubles and stacks.

Pick an audio file to begin.

Drop an MP3 named song.mp3 next to this file and it loads automatically, or add ?song=mytrack.mp3 to the URL.
In the headset: B or Y opens the menu. If blocks feel out of step with the music, turn the metronome on — if the clicks don't match the song, the tempo detection missed and no offset will fix it.
